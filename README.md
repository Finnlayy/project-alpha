## What is this?

Projekt:Alpha is the master architecture specification and Python/TypeScript skeleton for a Level-4 autonomous crypto trading system built on:

- **Redis Lua state machine** (ACTIVE → THROTTLED → QUARANTINED → RETIRED)
- **Vault profit sweep** with high-water-mark budget recovery
- **Trade autopsy** (MFE/MAE zones, R-multiples)
- **Genetic optimizer** with multi-objective fitness and cadence bandpass
- **Passkey-gated** settings and mutative commands

The full frozen spec lives in [`docs/BLUEPRINT-v1.2.0.md`](docs/BLUEPRINT-v1.2.0.md).
